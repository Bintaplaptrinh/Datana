# Data Engineer Tool Frontend

Next.js workspace for the Data Engineer Tool API. It uses Material UI, Google Sans Flex,
Google Material Symbols, a white translucent interface, a CSV/raw Data Wrangler, and
draggable crawl monitoring panels.

See [../README.md](../README.md) for full setup and backend instructions.

```powershell
npm install
npm run dev
```

The default API URL is `http://localhost:8000/api`. Copy `.env.local.example` to
`.env.local` when a different API host is needed.
